## ⚠️ Domain Verification - TODO

**Action Required:** Verify ownership of https://www.appauro.com/

### How to Verify Domain Ownership:

#### Option 1: Google Search Console (Recommended)
1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add property: `https://www.appauro.com`
3. Choose verification method:
   - **HTML file upload** (easiest for Next.js)
   - **HTML tag** (add to site/app/layout.tsx)
   - **DNS record** (if you manage DNS)
4. Complete verification
5. In Google Cloud Console, link your verified domain

#### Option 2: Google Cloud Console Direct
1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Navigate to **APIs & Services → OAuth consent screen**
3. Under "Authorized domains", add `appauro.com`
4. Click "Verify domain" and follow instructions

#### Option 3: DNS TXT Record
1. Add a TXT record to your DNS with Google's verification string
2. Google will check for this record to confirm ownership
3. This is the most permanent method

### Files to Upload (if using HTML file method):
You'll need to place a verification file in your `site/public/` directory that Google provides.
