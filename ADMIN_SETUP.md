# Admin Panel Setup

## Environment Variable

Set this in Vercel environment variables:

- **Key:** `CHEESEWAFFLE`
- **Value:** Your admin password (choose a strong password)
- **Environment:** Production (and Preview if needed)

## Access

1. Go to: `https://www.appauro.com/admin/payments`
2. Enter the password you set in `CHEESEWAFFLE`
3. Click "Sign In"

## Features

- Retry failed payment distributions
- Process timeout refunds
- View payment statistics
- View pending payments
- Refresh data

---

**Note:** The environment variable is named `CHEESEWAFFLE` for security through obscurity. Keep it secret!
