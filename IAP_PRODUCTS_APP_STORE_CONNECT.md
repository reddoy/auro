## Important Notes

### Product ID Format
- **Must match exactly**: `com.auro.app.review.{tier}`
- No spaces, no extra characters
- Use the exact format shown above

### IAP Price Selection
- If the exact IAP price isn't available in the dropdown, select the **closest match**
- The system will still work correctly
- Example: If $108 isn't available, use $109 or $107

### Reference Name
- This is just for your reference in App Store Connect
- Can be customized, but Product ID must match exactly

### Product Type
- Recommended: **Non-Consumable**
- Alternative: **Consumable** (if you prefer)

## Step-by-Step Creation Process

1. **Go to App Store Connect**
   - https://appstoreconnect.apple.com
   - Your App → Features → In-App Purchases

2. **For Each Product:**
   - Click "+" button
   - Select "Non-Consumable"
   - **Product ID**: Copy from table above (e.g., `com.auro.app.review.75`)
   - **Reference Name**: Copy from table above (e.g., `Review Request - $75`)
   - **Price**: Select IAP Price from dropdown (e.g., $108.00)
   - Click "Save"

3. **Repeat for all 35 products**
